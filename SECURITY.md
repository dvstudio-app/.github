# Security policy

Report a vulnerability in VoiceWink or any other DV Studio software by email to
**security@dvstudio.app**. Do not open a public issue for it.

Include what you found, how to reproduce it, and the version (the About page in the app).
We acknowledge reports by email and tell you when a fix ships.

Only the latest release published at <https://voicewink.app> receives fixes.

Machine-readable contact: <https://voicewink.app/.well-known/security.txt>
