# Support

- **In the app:** About → Report a problem. It builds a report with API keys and license keys
  removed and opens it in your mail client, addressed to support@dvstudio.app.
- **Email:** support@dvstudio.app
- **Product information and downloads:** <https://voicewink.app>

GitHub issues are public. Do not paste log files, your license key, or screenshots that show
personal data into an issue. Send those by email instead.
